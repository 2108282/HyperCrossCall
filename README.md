# HyperCrossCall (小米跨设备双手机通话流转 LSPosed 模块)

专为小米 **HyperOS 3.0 (Android 16 / API 36)** 打造的现代 LSPosed 模块，旨在打破小米互联“跨设备通话仅支持手机流转到平板/PC”的硬编码限制，使两台小米手机之间亦能实现完整的跨设备通话流转。

---

## 🌟 互联运行模式 (二选一)

### 模式一：【双端对等互联 (推荐)】
- **使用场景**：两台手机均已 Root 并安装本模块。
- **工作机制**：双向互为主从，A 来电 B 能接，B 来电 A 也能接，听筒、贴耳防误触和硬件 AEC 全双工生效，体验最自由。

### 模式二：【副机单端接听 (免改主力机)】
- **使用场景**：主力机（插日常 SIM 卡）注重银行/企业安全软件，**未解 BL 锁、未 Root、不装任何模块**；仅备用副机已 Root。
- **工作机制**：只在接听副机上开启！副机在互联握手协议中主动向主力机声明自身为平板设备（`PAD`）。主力机毫无感知地将电话推向副机，副机在本地接管下行音频送入听筒并启动贴耳息屏。

---

## 🚀 核心声学与硬件接管特性

1. **物理听筒定向流转（TYPE_BUILTIN_EARPIECE）**：关闭免提外放，声音直接送入顶部听筒。
2. **贴耳感应息屏防误触**：持有系统底层 `PROXIMITY_SCREEN_OFF_WAKE_LOCK`，贴耳自动灭屏，拿开自动点亮。
3. **硬件级回声消除（AEC）**：绑定芯片音频 HAL 硬件通道，彻底消除双机对讲回声与啸叫。
4. **原生系统通话架构接管（CallKit）**：流转通话期间若副机自身 SIM 卡来电，系统原生弹出仲裁接听菜单，不崩溃不抢占。
